# Синий конверт

Мобильное веб-приложение благодарности за рекомендации для риелтора Николая Калиберды.

## Публикация

`index.html` — статическая клиентская часть. `.github/workflows/pages.yml` публикует её в GitHub Pages при push в `main`. В настройках репозитория нужно выбрать **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Серверная часть

- `supabase/schema.sql` описывает таблицы и ограничения доступа.
- `supabase/functions/sinij-konvert-api/index.ts` — API для клиентских рекомендаций, кошелька, статусов сделок и профиля риелтора.
- Секретный ключ Supabase используется только в Edge Function; ключ для браузера — publishable.
- Риелтор входит по адресу электронной почты и паролю Supabase Auth. Доступ клиента к его лидам и конвертам выдаётся персональной ссылкой.
- В браузере данные не сохраняются в `localStorage`.

## Первый запуск

Создайте пользователя риелтора в Supabase Auth (**Authentication → Users → Add user**). Триггер добавит профиль с начальными данными. Затем войдите в опубликованное приложение как риелтор и заполните действующие реквизиты на вкладке «Награды».

Публичный сайт не должен содержать реальные контакты клиентов или ключи Supabase с административными правами.
